# OpenStreetMap (OSM)

**Context in the journey:** OTP needs a street map for walking legs.

**What it is:** A free, editable map of the world built by volunteers. Think Wikipedia, but for maps. Anyone can add roads, buildings, footpaths, bus stops, etc.

**Why we need it:** OTP uses OSM data to build the street network so it can calculate walking routes between your start point and the nearest bus stop, and between your last stop and your destination.

**Key terms:**
- **`.pbf`** — Binary file format for OSM data. Compressed and fast to parse.
- **Extract** — A cut-out of the global map (e.g., Egypt instead of the whole planet).

**Our file:** `otp/egypt-latest.osm.pbf` (~168MB), downloaded from [Geofabrik](https://download.geofabrik.de/africa/egypt-latest.osm.pbf).
