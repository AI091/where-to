# Multimodal Trip Planning

**Context in the journey:** This was the starting point — the first concept I learned.

**What it is:** Combining multiple transport modes (walk + bus + tram + microbus) into one journey. Not just looking up a single bus route, but finding the optimal combination to get from A to B.

**Why we need it:** This is literally what the app does. A commuter doesn't care which bus number — they care about the fastest way to get to work. Multimodal planning figures that out.

**Tool that does this:** [OpenTripPlanner (OTP)](https://docs.opentripplanner.org/) — takes a street map + transit schedules and computes optimal routes.
